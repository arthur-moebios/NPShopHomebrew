# 🎮 What is NPShop?

**NPShop** is a complete ecosystem designed to manage your **Nintendo Switch homebrew library**.

It consists of two main components:

### 1️⃣ NPShop Homebrew App
A Switch application that allows you to:

- Browse your library
- Install games, updates and DLC
- Manage save backups
- Download files directly from cloud storage

### 2️⃣ NPShop.org Web Panel
A cloud dashboard used to:

- Manage your game library
- Upload backups
- Generate encrypted Tinfoil indexes
- Manage devices and authentication

Together they create a **powerful personal game backup manager** for Nintendo Switch.

# 🇧🇷 Português (Brasil)

## Visão Geral

O **NPShop** é um **ecossistema completo** para gerenciamento de bibliotecas homebrew no Nintendo Switch.

Ele é composto por:

### 📱 Aplicativo Homebrew
Aplicativo que roda diretamente no Nintendo Switch permitindo:

- Navegar sua biblioteca
- Instalar jogos, updates e DLCs
- Gerenciar saves
- Baixar arquivos diretamente da nuvem

### 🌐 Painel Web (NPShop.org)

Painel online usado para:

- Gerenciar sua biblioteca
- Enviar backups
- Gerar catálogos Tinfoil
- Gerenciar dispositivos
- Sincronizar saves

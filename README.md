# NPShop

A homebrew menu for the Nintendo Switch.

## Bug reports

For any bug reports, please use the **Issues** tab and explain in as much detail as possible!

Please include:

- CFW type (Atmosphere assumed, but others may still exist);
- CFW version;
- FW version;
- The bug itself and clear reproduction steps.

---

## Installing (applications)

NPShop can install applications (.nsp, .xci, .nsz, .xcz) from your private Nintendo Personal Shop on www.npshop.org for free with your Google Drive account
